# Architecture

High-level architecture, components, responsibilities, dependencies, and boundaries.

## System Overview

Seamus is a deep agent harness engineered for full developer ownership, inspection, and customization. It provides the execution harness, tool mediation, memory/context structures, and agent lifecycle management over DeepAgent.

```
+---------------------------------------------------------------------------------+
|                                     Seamus                                      |
|                                                                                 |
|  +---------------------------------------------------------------------------+  |
|  |                             React Web UI                                  |  |
|  |         [Sidebar Navigation Tree]  <--->  [Real-Time Chat & Tool Cards]   |  |
|  |         [In-Browser JSON Config Editor Modal]                             |  |
|  +---------------------------------------------------------------------------+  |
|                                       | (HTTP REST & SSE Stream)                |
|                                       v                                         |
|  +---------------------------------------------------------------------------+  |
|  |                             FastAPI Server                                |  |
|  |                       (Prefix: /api/v-alpha/)                             |  |
|  |   +---------------------+   +---------------------+   +---------------+   |  |
|  |   |   Config Template   |   |   Agents & Sessions |   | Threads & SSE |   |  |
|  |   +---------------------+   +---------------------+   +---------------+   |  |
|  +---------------------------------------------------------------------------+  |

|                                       v                                         |
|  +---------------------------------------------------------------------------+  |
|  |                             Domain & Store                                |  |
```

## Component Boundaries

1. **Web User Interface (`ui`)**:
   - Location: `ui/`
   - Responsibility: React 19 single-page application built with Vite and TypeScript. Houses navigation sidebar tree with external system integration footer, conversational message pane with client-side Markdown rendering (GFM, code blocks with copy-to-clipboard, safe external links, and table overflow protection), SSE streaming client, and in-browser JSON config editor.
2. **Configuration (`seamus.config`)**:
   - Location: `src/seamus/config/`
   - Responsibility: `InferenceConfig`, `AgentConfig`, and singleton `ConfigTemplate` management with copy-on-derive semantics and completeness validation.
3. **Domain Entities (`seamus.domain`)**:
   - Location: `src/seamus/domain/`
   - Responsibility: Models for `Agent`, `Session`, `Thread`, and `AgentStatus`. Dual-resolution logic mapping UUIDs and slugs to entities.
4. **Harness & Runner (`seamus.harness`)**:
   - Location: `src/seamus/harness/`
   - Responsibility: In-memory store repository with Gitea hydration, `SessionAgentRunner` wrapping `create_deep_agent`, `SeamusOpenSandboxBackend` integrating `langchain-sandbox-opensandbox` (`OpenSandboxBackend`) with a containerized local `opensandbox-server` and runtime-autogenerated API authentication, `ReasoningChatOpenAI`, `SeamusLangGraphAgent`, and event broadcasting/replay queues.
5. **Persistence & Git Workspace (`seamus.persistence`)**:
   - Location: `src/seamus/persistence/`
   - Responsibility: Gitea REST API client (`GiteaClient`), workspace clone/branch management (`GitWorkspaceManager`), and checkpoint-driven Git commits (`GitCheckpointSaver`). Maintains strict separation between `agent/config/`, `agent/state/`, and agent-accessible `data/` (mounted into the OpenSandbox container at `/workspace`). Persists thread events (`events.json`), checkpoints/HITL state (`checkpoints.json`), and human-readable messages (`messages.json`).
6. **Server & REST API (`seamus.server`)**:
   - Location: `src/seamus/server/`
   - Responsibility: FastAPI application factory mounted at `/api/v-alpha/`, Pydantic request/response schemas, routes for config template, agents, sessions, input dispatch, thread redirection, system integration metadata (`/api/v-alpha/system/info`), and SSE streaming. Optionally serves built `ui/dist` bundle in production.
7. **Telemetry & Observability (`seamus.telemetry`)**:
   - Location: `src/seamus/telemetry.py`
   - Responsibility: Logfire initialization, evaluation of `LOGFIRE_SEND_TO_LOGFIRE`, custom domain scrubbing (preserving `session`), FastAPI request instrumentation with `/health` exclusions, and OpenTelemetry environment setup for LangChain/LangGraph tracing.
8. **Decisions (`decisions`)**:
   - Location: `decisions/`
   - Responsibility: Append-only architectural and project direction decision records.
9. **Knowledge (`knowledge`)**:
   - Location: `knowledge/`
   - Responsibility: Durable conceptual, architectural, and requirement specifications.
