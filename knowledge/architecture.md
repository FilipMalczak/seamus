# Architecture

High-level architecture, components, responsibilities, dependencies, and boundaries.

## System Overview

Seamus is a deep agent harness engineered for full developer ownership, inspection, and customization. It provides the execution harness, tool mediation, memory/context structures, and agent lifecycle management over DeepAgent.

```
+---------------------------------------------------------------------------------+
|                                     Seamus                                      |
|                                                                                 |
|  +---------------------------------------------------------------------------+  |
|  |                             React Web UI                                  |  |
|  |         [Sidebar Navigation Tree]  <--->  [Real-Time Chat & Tool Cards]   |  |
|  |         [In-Browser JSON Config Editor Modal]                             |  |
|  +---------------------------------------------------------------------------+  |
|                                       | (HTTP REST & SSE Stream)                |
|                                       v                                         |
|  +---------------------------------------------------------------------------+  |
|  |                             FastAPI Server                                |  |
|  |                       (Prefix: /api/v-alpha/)                             |  |
|  |   +---------------------+   +---------------------+   +---------------+   |  |
|  |   |   Config Template   |   |   Agents & Sessions |   | Threads & SSE |   |  |
|  |   +---------------------+   +---------------------+   +---------------+   |  |
|  +---------------------------------------------------------------------------+  |
|                                       |                                         |
|                                       v                                         |
|  +---------------------------------------------------------------------------+  |
|  |                             Domain & Store                                |  |
|  |    Agent (UUID/Slug)  --->   Session (UUID/Slug)  --->  Thread (UUID/Slug) |  |
|  |    Complete Config           Copied Config              Single Open Thread|  |
|  +---------------------------------------------------------------------------+  |
|                                       |                                         |
|                                       v                                         |
|  +---------------------------------------------------------------------------+  |
|  |                          Harness & Execution                              |  |
|  |    SessionAgentRunner  --->  DeepAgent (GitCheckpointSaver)               |  |
|  |    SeamusOpenSandboxBackend  --->  OpenSandbox Server (Containerized)     |  |
|  |    AG-UI Event Broadcaster (Pub-Sub & History Replay)                     |  |
|  +---------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------+
```

## Component Boundaries

1. **Web User Interface (`ui`)**:
   - Location: `ui/`
   - Responsibility: React 19 single-page application built with Vite and TypeScript. Arranged with a draggable split resizer defaulting to a 50/50 balanced proportion between the navigation sidebar tree (with external system integration footer) and the main panel, with boundary clamping and local storage preference persistence. Houses top-level workspace tabs (`[Chat] | [Inspector]`), multiline wrapping breadcrumb top bar with "Accept" action button initiating thread acceptance and Sync PR lifecycle, conversational message pane with client-side Markdown rendering (GFM, code blocks with copy-to-clipboard, safe external links, and table overflow protection), DeepAgent Inspector (displaying composite/scaffold system prompts, tool schemas, inference runtime parameters, and message trajectory), SSE streaming client, and in-browser JSON config editor.
2. **Configuration (`seamus.config`)**:
   - Location: `src/seamus/config/`
   - Responsibility: `InferenceConfig`, `AgentConfig`, and singleton `ConfigTemplate` management with copy-on-derive semantics, optional system prompt extension, and completeness validation.
3. **Domain Entities (`seamus.domain`)**:
   - Location: `src/seamus/domain/`
   - Responsibility: Models for `Agent`, `Session`, `Thread`, and `AgentStatus`. Dual-resolution logic mapping UUIDs and slugs to entities.
4. **Harness & Runner (`seamus.harness`)**:
   - Location: `src/seamus/harness/`
   - Responsibility: In-memory store repository with Gitea hydration, `SessionAgentRunner` wrapping `create_deep_agent`, `SeamusOpenSandboxBackend` integrating `langchain-sandbox-opensandbox` (`OpenSandboxBackend`) with a containerized local `opensandbox-server` and runtime-autogenerated API authentication, `ReasoningChatOpenAI`, `SeamusLangGraphAgent`, agent inspector service (`seamus.harness.inspector`) for semi-live runtime and branch state extraction, and event broadcasting/replay queues.
5. **Persistence & Git Workspace (`seamus.persistence`)**:
   - Location: `src/seamus/persistence/`
   - Responsibility: Gitea REST API client (`GiteaClient`), workspace clone/branch management (`GitWorkspaceManager`), and checkpoint-driven Git commits (`GitCheckpointSaver`). Maintains strict separation between `agent/config/`, `agent/state/`, and agent-accessible `data/` (mounted into the OpenSandbox container at `/workspace`). Orchestrates Gitea Sync PR lifecycle (`open_sync_pr`, `merge_sync_pr`) linking session branches to `main` with merges strictly scoped to `data/` deliverables. Persists thread events (`events.json`), checkpoints/HITL state (`checkpoints.json`), and human-readable messages (`messages.json`), with git commit provenance extraction.
6. **Server & REST API (`seamus.server`)**:
   - Location: `src/seamus/server/`
   - Responsibility: FastAPI application factory mounted at `/api/v-alpha/`, Pydantic request/response schemas, routes for config template, agents, sessions, agent inspection (`/api/v-alpha/agent/{agent}/session/{session}/inspect`), session diff inspection (`/api/v-alpha/agent/{agent}/session/{session}/diff`), thread acceptance (`/api/v-alpha/agent/{agent}/session/{session}/thread/{thread}/accept`), input dispatch, thread redirection, system integration metadata (`/api/v-alpha/system/info`), and SSE streaming. Optionally serves built `ui/dist` bundle in production.
7. **Telemetry & Observability (`seamus.telemetry`)**:
   - Location: `src/seamus/telemetry.py`
   - Responsibility: Logfire initialization, evaluation of `LOGFIRE_SEND_TO_LOGFIRE`, custom domain scrubbing (preserving `session`), FastAPI request instrumentation with `/health` exclusions, and OpenTelemetry environment setup for LangChain/LangGraph tracing.
8. **Decisions (`decisions`)**:
   - Location: `decisions/`
   - Responsibility: Append-only architectural and project direction decision records.
9. **Knowledge (`knowledge`)**:
   - Location: `knowledge/`
   - Responsibility: Durable conceptual, architectural, and requirement specifications.
10. **Test Infrastructure & Isolation (`tests`)**:
   - Location: `tests/`
   - Responsibility: Test suites verifying unit, component, and persistence logic. `tests/conftest.py` orchestrates an ephemeral, SQLite-backed Gitea container fixture with dynamic port allocation and temporary workspace root, isolating the test suite from live development environments and enabling collision-free parallel execution.
